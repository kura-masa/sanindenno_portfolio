# shinonsen-townhall-punch

## 概要
新温泉町役場の打刻を、スマホのホーム画面に追加して使えるPWAにしたもの。GitHub Pagesで配信し、打刻データの読み書きは既存のGoogle Apps Script APIに対して行う。

## 使用技術
HTML / CSS / JavaScript、PWA、Service Worker、GitHub Pages、Google Apps Script API連携
